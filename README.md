# ls
Aplikasi pembuat latihan soal.
Masukkan file PDF/JSON/input manual soal sendiri(dan bisa combo!{menggunakan lebih dari 1 metode sekaligus di satu paket soal}), lalu kerjakan langsung di HP! Tanpa kertas, pensil, atau pulpen. Semua serba digital dan interaktif!
Sungguh nikmat bukan latihan langsung di hp tanpa harus duduk tegak dan menulis manual di kertas hitam-putih membosankan itu lagi?
